# 新旧版本迁移完整性审计

> 审计日期：2026-06-23
> 旧版：`src/app.js`（3267 行原生 JS 单文件）+ `src/index.html` + `src/config.js`
> 新版：`src/react-animal-island/`（React 19 + TypeScript + Vite，21 个 domain 模块）
> 后端：PHP `src/api/state.php` + `reset.php`，新旧共用，不变

## 方法

1. 旧版 207 个顶层函数 + 全部视图/弹窗，按功能域切 4 块并行核对。
2. agent 给出的每条「缺失/偏差」结论均**人工 grep + 读源码二次验证**。
3. 纠正 1 处误报（`sharedEvents` 实已迁移）。
4. 数值类偏差用 `scripts/parity-diff.mjs` 逐日量化（见末尾）。
5. 单测 128/128 全过只能证明「已迁移逻辑自洽」，无法证明「与旧版等价」或「UI 接上了」，故本审计独立于单测。

## 总结论

**核心功能约 95% 已迁移。存在 7 个真实缺口 + 6 处数值/语义偏差。**
全部为非致命，但 🔴 一项需优先决策。

> **审计纠错**：初版曾把「localStorage 本地持久化」列为 🔴 缺口。
> 复核发现旧版 `loadLocal/saveLocal`（app.js:586/590）**本身就是空函数**，注释明确写
> 「Browser persistence is intentionally not used. Server state is the source of truth」。
> 即旧版自己早已废弃浏览器本地缓存（避免刷新后回灌过期数据），新版无 localStorage 是**正确对齐**，非漏迁。已撤回该条。

## ⚠️ 数值/语义偏差（迁移了但结果可能不同）
