# Nav Icon Sources

These bottom-navigation icons are local original SVG assets created for this private Fitness Island page.

They were designed after reviewing the visual direction and naming references listed in `doc/difficulty-hidden-v2-design.md`:

- Nintendo official Animal Crossing: New Horizons site: https://animalcrossing.nintendo.com/new-horizons/
- Nookipedia NookPhone reference: https://nookipedia.com/wiki/NookPhone
- Nookipedia New Horizons sprites category: https://nookipedia.com/wiki/Category:New_Horizons_sprites
- Fandom New Horizons icons category: https://animalcrossing.fandom.com/wiki/Category:Icons_(New_Horizons)

No external icon file is embedded in this folder. If this page is ever published beyond private use, keep these original SVGs or replace any official-style references with fully original assets.
